# /robar-como-artista — Skill para Claude Code

Ingeniería inversa de videos virales. Analiza la estructura de un video exitoso y escribe un guión nuevo con tu tema, manteniendo la misma fórmula emocional ganadora.

> "Copiar de uno es plagio. Copiar de varios es inspiración." — Austin Cleon

## Instalación

```bash
cp SKILL.md ~/.claude/commands/robar-como-artista.md
```

O con npx skills (si está disponible en el registry):

```bash
npx skills add tahecolors-cloud/robar-como-artista-skill
```

## Uso

En Claude Code:

```
/robar-como-artista
```

O con atajo directo:

```
/robar-como-artista [URL del video de referencia]
```

## Qué hace

Proceso de 5 pasos para transformar cualquier video viral de referencia en un guión nuevo adaptado a tu nicho:

1. **Recibir material** — transcripción del video de referencia + tu tema + audiencia + estilo
2. **Diseccionar** — hook (tipo + emoción + estructura), conectores, desarrollo, cierre
3. **Ingeniería inversa del hook** — 3 variantes adaptadas a tu tema con la misma estructura emocional
4. **Guión completo** — con timestamps, formato y conectores adaptados a tu voz
5. **Análisis** — por qué tiene potencial viral (hook, ritmo, cierre, similitud estructural)

## Filosofía

Copia la ESTRUCTURA, no el contenido. El hook es la pieza más valiosa — no lo cambies. Los conectores deben sonar como tú, no como el video original.
